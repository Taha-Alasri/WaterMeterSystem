## 📖 نظرة عامة

**WaterMeterSystem** هو تطبيق سطح مكتب مبني بلغة **Java** باستخدام واجهة رسومية (**GUI**)، صُمم لتبسيط عملية **قراءة عدادات المياه وحساب كمية الاستهلاك** بطريقة دقيقة وسهلة الاستخدام.

يهدف المشروع إلى استبدال الطرق اليدوية التقليدية في تسجيل قراءات العدادات بحل رقمي منظم، يقلل من الأخطاء البشرية، ويسرّع عملية احتساب الاستهلاك، ويوفر واجهة واضحة لإدخال البيانات ومتابعتها.

---

## ✨ المميزات الرئيسية

- 📊 **إدخال قراءات العداد** بسهولة عبر واجهة رسومية بسيطة وسلسة
- 🧮 **حساب تلقائي للاستهلاك** بناءً على الفرق بين القراءة الحالية والسابقة
- 🖥️ **واجهة مستخدم رسومية (Java Swing)** سهلة التعامل لجميع المستخدمين
- ⚡ **أداء سريع وخفيف** لا يحتاج إلى موارد كبيرة
- 🗂️ **بنية مشروع منظمة** تتبع معايير NetBeans القياسية لسهولة الصيانة والتطوير
- 🔧 **قابل للتوسعة** لإضافة ميزات مستقبلية مثل الفوترة أو قواعد البيانات

## 🚀 طريقة التشغيل

### المتطلبات
- Java Development Kit (JDK) مثبت على جهازك (يفضّل إصدار 8 أو أحدث)
- (اختياري) بيئة NetBeans IDE لفتح المشروع والتعديل عليه

### خطوات التشغيل

**1. استنساخ المستودع**
```bash
git clone https://github.com/Taha-Alasri/WaterMeterSystem.git
cd WaterMeterSystem
```

**2. التشغيل عبر NetBeans**
- افتح NetBeans IDE
- اختر `Open Project` وحدد مجلد المشروع
- اضغط زر `Run` ▶️

**3. التشغيل عبر سطر الأوامر (باستخدام ملف JAR الجاهز)**
```bash
java -jar dist/WaterMeterSystem.jar
```
